# One Ustam repository

The maintained source, current README, downloads and new releases are at [metapak/ustam](https://github.com/metapak/ustam). The existing Codex repository is renamed so its history, repository identity, issues, stars and previous releases stay attached. Its former URL redirects to Ustam.

The former Claude Code and OpenCode repositories retain their history and earlier releases, with a migration notice and archive status. Their README links lead here; archive status is not an automatic HTTP redirect. Do not recreate the old Codex repository name, because that would break GitHub's rename redirect.

All four provider engines are bundled from source-only snapshots in this repository and verified by immutable commit/file hashes. Their original license and attribution files remain included. Installation uses the bundled closure, without fetching sibling repositories or provider engine source from GitHub. Provider CLIs, accounts and available models remain separate requirements.

The current download is explicitly linked to the beta.5 prerelease. GitHub's generic latest-release URL can point to an older stable release. Historical release tags and assets are retained; Windows/Linux beta.2 packages represent the older three-tool version.
