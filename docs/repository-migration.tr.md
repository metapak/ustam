# Tek Ustam deposu

Bakımı sürdürülen kaynak, güncel README, indirmeler ve yeni sürümler [metapak/ustam](https://github.com/metapak/ustam) adresindedir. Mevcut Codex deposu yeniden adlandırılır; geçmişi, depo kimliği, issue'ları, yıldızları ve önceki sürümleri aynı depoda kalır. Eski adresi Ustam'a yönlenir.

Önceki Claude Code ve OpenCode depoları geçmişlerini ve eski sürümlerini korur; geçiş açıklamasıyla arşivlenir. README bağlantıları buraya getirir; arşiv durumu otomatik HTTP yönlendirmesi değildir. Eski Codex depo adını yeniden oluşturmayın; bu GitHub'ın yeniden adlandırma yönlendirmesini bozar.

Dört sağlayıcının motorları bu depodaki yalnız kaynak içeren anlık görüntülerden paketlenir, değişmez commit/dosya hash'leriyle doğrulanır. Özgün lisans ve atıf dosyaları korunur. Kurulum kardeş depo veya GitHub'dan sağlayıcı motor kaynağı çekmeden paketlenen dosyaları kullanır. Sağlayıcı CLI'ları, hesapları ve erişilebilir modeller ayrı gerekliliklerdir.

Güncel indirme beta.5 ön sürümüne açıkça bağlanır. GitHub'ın genel latest-release adresi daha eski bir kararlı sürümü gösterebilir. Geçmiş sürüm etiketleri ve ekleri korunur; Windows/Linux beta.2 paketleri eski üç araçlı sürümü temsil eder.
