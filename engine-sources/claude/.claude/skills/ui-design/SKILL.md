# UI design expertise

Use this skill only when explicitly invoked for the current task.

1. Have the assigned specialist inspect the existing product language, components, tokens, and target platform before proposing changes. The main session coordinates from its short evidence report.
2. State the user goal, primary action, information hierarchy, states, and accessibility needs.
3. Reuse established components and spacing, typography, color, and motion rules where they exist.
4. Design empty, loading, error, disabled, focus, and narrow-screen states when relevant.
5. Avoid generic decoration that does not help comprehension or action.
6. Keep implementation within the owner's assigned scope and the one-writer rule.

This skill supplies guidance only. It does not grant tools, file access, external access, or permission to edit.
