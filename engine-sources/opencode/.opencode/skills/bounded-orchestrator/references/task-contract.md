# Task contract

Each delegated task names its objective, owned files or subsystem, acceptance criteria, allowed checks, dependencies, and stop conditions. Only the implementer may receive write ownership.

A brief should be self-contained and scoped, usually a few short paragraphs: objective; owned paths; acceptance checks; constraints/dependencies; evidence pointers; stop conditions. Share excerpts or paths instead of transcripts. The reviewer gets an independent brief for the frozen candidate.

Default to one specialist. Document why independent parallel work will reduce latency or context before launching more. Resume a relevant child only if OpenCode provides that capability. Do not assume Codex-specific spawn, messaging, or wait tools exist.
